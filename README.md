# 🍔 Minute Burger Ordering System

A responsive, single-page web app for a burger restaurant. Features a functional shopping cart, category filtering, and a checkout UI with localized payment options.

## ✨ Features
* **Interactive Menu:** Filter by category (Burgers, Hotdogs, Sides, Drinks).
* **Cart System:** Add/remove items, adjust quantities, and see real-time price totals.
* **Checkout UI:** Toggle Delivery/Pickup and choose payment methods (Cash, GCash, Maya) with dynamic fields.
* **Responsive:** Looks great on both mobile and desktop.

## 🛠️ Tech Stack
* HTML5 & Vanilla JavaScript
* Tailwind CSS (via CDN)
* Lucide Icons

## 🚀 How to Run
1. Download or clone this repository.
2. Open `index.html` directly in any web browser.
*(Tip: Use VS Code's "Live Server" extension for the best experience).*

## 🌐 Deployment
This static site is ready for instant, free deployment on [Vercel](https://vercel.com), [GitHub Pages](https://pages.github.com), or [Netlify](https://www.netlify.com).
